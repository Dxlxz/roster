## Prezentare generală

Utilizați CLI-ul independent pentru a genera un obiect, un câmp, o regulă de validare, o funcție logică sau o componentă front-end:

```bash
roster app add
roster app add object --name invoice --name-plural invoices --no-input
roster app add field --name amount --type NUMBER --object <object-uuid> --no-input
roster app add validation-rule --name invoice-has-amount --object <object-uuid> --no-input
roster app add logic-function --name send-invoice --no-input
roster app add front-component --name invoice-panel --no-input
```

Fără flag-uri, terminalele interactive solicită valorile lipsă. Pentru scripturi și agenți, furnizați câmpurile obligatorii și utilizați `--no-input` sau `--json`.

Generarea obiectelor poate crea și o vizualizare, un element de navigare și un aspect al paginii de înregistrare:

```bash
roster app add object --name invoice --name-plural invoices \
  --create-view --create-navigation-menu-item --create-page-layout --no-input
```

Pentru alte tipuri de entități, scrieți fișierul `define*` corespunzător folosind `roster-sdk/define` și un UUID v4 valid. Rulați `roster app typecheck` și `roster app plan` înainte de sincronizare.

`--path` selectează directorul aplicației, nu un folder de ieșire personalizat. Rulați `roster app add --help` pentru opțiunile acceptate.
