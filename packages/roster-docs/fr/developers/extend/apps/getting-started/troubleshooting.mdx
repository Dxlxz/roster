---
title: Résolution des problèmes
description: Problèmes courants lors de la première exécution — Docker, version de Node, Yarn, dépendances.
---

* **Erreurs Docker** — Assurez-vous que Docker Desktop (ou le démon) est en cours d’exécution avant `yarn roster docker:start`. Le message d’erreur indiquera la bonne commande de démarrage pour votre système d’exploitation.
* **Mauvaise version de Node** — Version 24.5+ requise (`engines.node: ^24.5.0`). Vérifiez avec `node -v`.
* **Yarn 4 manquant** — Exécutez `corepack enable`.
* **Dépendances cassées** — `rm -rf node_modules && yarn install`.
* **Erreurs de `roster-sdk` après la mise à niveau vers la v2.8.0** — il est passé de `dependencies` à `devDependencies` dans la v2.8.0. Voir [Structure du projet → Dépendances](/fr/developers/extend/apps/getting-started/project-structure#dependencies).
* **`roster dev:build` avertit au sujet de `roster-client-sdk` dans `dependencies`** — il est fourni au moment de l'exécution par roster, donc il devrait être déplacé vers `devDependencies` avec `roster-sdk`. Voir [Structure du projet → Dépendances](/fr/developers/extend/apps/getting-started/project-structure#dependencies).
