## Overview

Use the standalone CLI to generate an object, field, validation rule, logic function, or front component:

```bash
roster app add
roster app add object --name invoice --name-plural invoices --no-input
roster app add field --name amount --type NUMBER --object <object-uuid> --no-input
roster app add validation-rule --name invoice-has-amount --object <object-uuid> --no-input
roster app add logic-function --name send-invoice --no-input
roster app add front-component --name invoice-panel --no-input
```

Without flags, interactive terminals prompt for missing values. For scripts and agents, supply the required fields and use `--no-input` or `--json`.

Object generation can also create a view, navigation item, and record page layout:

```bash
roster app add object --name invoice --name-plural invoices \
  --create-view --create-navigation-menu-item --create-page-layout --no-input
```

For other entity types, write the corresponding `define*` file using `roster-sdk/define` and a valid UUID v4. Run `roster app typecheck` and `roster app plan` before syncing.

`--path` selects the app directory, not a custom output folder. Run `roster app add --help` for supported options.
