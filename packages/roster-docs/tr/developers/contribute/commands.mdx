---
title: Komutlar
description: roster geliştirmek için yararlı komutlar.
---

Komutlar, deponun kök dizininden `npx nx` kullanılarak çalıştırılabilir. Açık hedefleme için `npx nx run {project}:{command}` kullanın.

## Uygulamayı Başlatma

```bash
npx nx start roster-front          # Frontend dev server (http://localhost:3001)
npx nx start roster-server         # Backend server (http://localhost:3000)
npx nx run roster-server:worker    # Background worker
```

## Veritabanı

```bash
npx nx database:reset roster-server                          # Reset and seed database
npx nx run roster-server:database:migrate:prod               # Run migrations
npx nx run roster-server:database:migrate:generate --name <name> --type <fast|slow>  # Generate a migration
```

## Lint denetimi

```bash
npx nx lint:diff-with-main roster-front    # Lint changed files (fastest)
npx nx lint:diff-with-main roster-server
npx nx lint roster-front --configuration=fix  # Auto-fix
```

## Tip denetimi

```bash
npx nx typecheck roster-front
npx nx typecheck roster-server
```

## Test

```bash
# Frontend
npx nx test roster-front                          # Jest unit tests
npx nx storybook:build roster-front               # Build Storybook
npx nx storybook:test roster-front                # Storybook tests

# Backend
npx nx run roster-server:test:unit                # Unit tests
npx nx run roster-server:test:integration         # Integration tests
npx nx run roster-server:test:integration:with-db-reset  # Integration with DB reset

# Single file (fastest)
npx jest path/to/test.test.ts --config=packages/{project}/jest.config.mjs
```

## GraphQL

```bash
npx nx run roster-front:graphql:generate                        # Regenerate types
npx nx run roster-front:graphql:generate --configuration=metadata  # Metadata schema
```

## Çeviriler

```bash
npx nx run roster-front:lingui:extract   # Extract strings
npx nx run roster-front:lingui:compile   # Compile translations
```

## Derleme

```bash
npx nx build roster-shared   # Must be built first
npx nx build roster-front
npx nx build roster-server
```
