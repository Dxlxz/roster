Varlık dosyalarını elle oluşturmak yerine etkileşimli iskelet oluşturucuyu kullanın:

```bash filename="Terminal"
yarn roster dev:add
```

Bir varlık türü seçmeniz için sizi yönlendirir ve gerekli alanlarda adım adım ilerlemenizi sağlar, ardından sabit bir `universalIdentifier` ve doğru `defineEntity()` çağrısıyla kullanıma hazır bir dosya yazar.

İlk istemi atlamak için varlık türünü doğrudan da geçebilirsiniz:

```bash filename="Terminal"
yarn roster dev:add object
yarn roster dev:add logicFunction
yarn roster dev:add frontComponent
```

## Kullanılabilir varlık türleri

| Varlık türü                   | Komut                                      | Oluşturulan dosya                                         |
| ----------------------------- | ------------------------------------------ | --------------------------------------------------------- |
| Nesne                         | `yarn roster dev:add object`               | `src/objects/\<name>.ts`                 |
| Alan                          | `yarn roster dev:add field`                | `src/fields/\<name>.ts`                  |
| Mantık işlevi                 | `yarn roster dev:add logicFunction`        | `src/logic-functions/\<name>.ts`         |
| Ön uç bileşeni                | `yarn roster dev:add frontComponent`       | `src/front-components/\<name>.tsx`       |
| Rol                           | `yarn roster dev:add role`                 | `src/roles/\<name>.ts`                   |
| Beceri                        | `yarn roster dev:add skill`                | `src/skills/\<name>.ts`                  |
| Temsilci                      | `yarn roster dev:add agent`                | `src/agents/\<name>.ts`                  |
| Görünüm                       | `yarn roster dev:add view`                 | `src/views/\<name>.ts`                   |
| Gezinme menüsü öğesi          | `yarn roster dev:add navigationMenuItem`   | `src/navigation-menu-items/\<name>.ts`   |
| Sayfa düzeni                  | `yarn roster dev:add pageLayout`           | `src/page-layouts/\<name>.ts`            |
| Sayfa düzeni sekmesi          | `yarn roster dev:add pageLayoutTab`        | `src/page-layout-tabs/\<name>.ts`        |
| Komut menüsü öğesi            | `yarn roster dev:add commandMenuItem`      | `src/command-menu-items/\<name>.ts`      |
| Görünüm alanı                 | `yarn roster dev:add viewField`            | `src/view-fields/\<name>.ts`             |
| Bağlantı sağlayıcısı          | `yarn roster dev:add connectionProvider`   | `src/connection-providers/\<name>.ts`    |
| Zaman Çizelgesi Aktivite Türü | `yarn roster dev:add timelineActivityType` | `src/timeline-activity-types/\<name>.ts` |

## İskelet oluşturucunun ürettikleri

Her varlık türünün kendi şablonu vardır. Örneğin, `yarn roster dev:add object` şunları sorar:

1. **Ad (tekil)** — ör. `invoice`
2. **Ad (çoğul)** — ör. `invoices`
3. **Etiket (tekil)** — adından otomatik doldurulur (ör. `Invoice`)
4. **Etiket (çoğul)** — otomatik doldurulur (ör. `Invoices`)
5. **Bir görünüm ve gezinme öğesi oluşturulsun mu?** — evet derseniz, iskelet oluşturucu yeni nesne için eşleşen bir görünüm ve kenar çubuğu bağlantısı da üretir.

Diğer varlık türlerinin istemleri daha basittir — çoğu yalnızca bir ad sorar.

`field` varlık türü daha ayrıntılıdır: alan adını, etiketi, türü (`TEXT`, `NUMBER`, `SELECT`, `RELATION` vb. gibi mevcut tüm alan türlerinin listesinden) ve hedef nesnenin `universalIdentifier` değerini sorar.

## Özel çıktı yolu

`--path` bayrağını kullanarak oluşturulan dosyayı özel bir konuma yerleştirin:

```bash filename="Terminal"
yarn roster dev:add logicFunction --path src/custom-folder
```
